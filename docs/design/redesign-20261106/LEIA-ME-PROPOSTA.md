# Proposta visual ChatISP — 06/11/2026

Estado: planejamento e conceito para avaliação, sem implementação no sistema publicado.

1. Abra `CONCEITO-CHATISP-DESKTOP-MOBILE.png` para visualizar a direção recomendada.
2. Leia `PLANO-REDESIGN-CHATISP.md` para arquitetura de informação, componentes, estados, reaproveitamento e etapas.
3. As capturas `chatisp-*` mostram a instalação atual; `chatwoot-referencia.png` é a imagem oficial versionada do Chatwoot, não uma sessão executada nesta rodada.
4. `AVALIACAO-VISUAL.md` registra o diagnóstico e os limites da comparação anterior.
5. `PROMPT-IMAGEM-CONCEITUAL.txt` contém o briefing completo usado na ferramenta nativa de geração de imagens. Não foram utilizadas API/CLI externas para gerar a imagem.

A imagem tem dados fictícios identificados e não comprova funcionamento, responsividade ou conexão ERP. O plano é a especificação mais precisa: proporções, acessibilidade e estados devem ser verificados no protótipo real. A imagem não determina funcionalidades novas nem substitui o contrato de autorização do backend.

Direção recomendada: tema claro, grafite e verde-petróleo; fila legível; conversa em destaque; contexto recolhível; celular com lista/conversa/detalhes em vistas próprias. As referências são Chatwoot (organização do atendimento), Linear (hierarquia e consistência) e Intercom (contexto e produtividade), com links no plano. Nenhum código ou asset comercial dessas referências foi incorporado ao produto.

Próxima etapa proposta: aprovação ou ajuste da direção, seguida de um protótipo isolado com dados sintéticos e os componentes React existentes. Não publicar nem alterar o banco operacional apenas para produzir uma demonstração visual.
